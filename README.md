# Joulies Website

Statische Website (HTML + CSS + etwas JavaScript), veröffentlicht über GitHub Pages.

## Aufbau

- `index.html`, `about.html`, `hoerproben.html`, `preise.html`, `repertoire.html`,
  `rezensionen.html`, `kontakt.html`: die einzelnen Seiten
- `css/style.css`: alle Styles, Farben als Variablen
- `js/main.js`: Burger-Menü auf dem Handy
- `assets/`: Logo und Bilder
- `STYLEGUIDE.md`: Farben, Schriften, Breakpoints

## Lokal ansehen

`index.html` einfach im Browser öffnen.

## Veröffentlichen mit GitHub Pages

Im Repository unter **Settings → Pages** bei „Build and deployment“
*Deploy from a branch* wählen, Branch `main` und Ordner `/ (root)`, speichern.
Nach ein bis zwei Minuten ist die Seite unter
`https://joulie1.github.io/joulie-website/` erreichbar.
